# TrayPerfmon

Windowsのシステムパフォーマンスをタスクトレイアイコンで監視するツールです。

## 機能

- タスクトレイアイコンでシステムパフォーマンスをリアルタイムに可視化
- プラグインアーキテクチャによる拡張性

## 標準プラグイン

- **CpuGraph**: CPU使用率をグラフ表示
  - マルチコア対応
  - 使用率に応じて色が変化（緑→黄→赤）

- **CpuGrid**: CPU使用率をヒートマップ格子で表示
  - 1セル=1物理コア（`GridMode` を `Logical` にすると論理CPU単位）
  - コア数に応じて格子を自動レイアウト（例: 16コア → 4×4）
  - 使用率に応じて色が連続的に変化（緑→黄→赤）
  - 多スレッド環境でも各コアの使用率が判読可能
  - 右クリックで平均使用率と最大使用率のコアを通知表示

- **MemoryMeter**: メモリ使用状況を表示
  - コミットメモリと物理メモリの使用率を円グラフで表示
  - 使用率に応じて色が変化（緑→黄→赤）

- **DiskQueueMonitor**: ディスクキュー長を監視
  - 読み取り/書き込みキュー長をグラフ表示
  - キュー長に応じて色が変化（緑→黄→赤）
  - 左クリックで監視対象の物理ディスクを選択（`_Total` または `0 C:` など）
  - 右クリックで現在のキュー長を通知表示

- **GpuMemory**: GPU 専用 VRAM 使用率を表示
  - `GPU Adapter Memory` の Dedicated Usage を監視（AMD / NVIDIA / Intel 等）
  - 使用率に応じて色が変化（緑→黄→赤）
  - 左クリックで監視対象 GPU を選択（設定は perf counter 用 `InstanceName` を保存）
  - 右クリックで使用率・使用量を通知表示

- **GpuUsage**: GPU エンジン使用率を表示
  - `GPU Engine` の Utilization Percentage を監視
  - 左クリックで GPU とエンジン種別（3D / Copy / Encode 等、Task Manager 相当）を選択
  - 該当 engtype の複数インスタンス値を合算して表示
  - 使用率に応じて色が変化（緑→黄→赤）
  - 右クリックで使用率を通知表示

## 操作

- プラグインアイコン: **左クリック** = 設定（設定 UI があるプラグインのみ）
- プラグインアイコン: **右クリック** = 通知（`BalloonTipText` があるプラグイン。MemoryMeter など設定なしプラグインもこちら）

## 必要条件

- Windows 10以降
- .NET 8.0 Runtime

## ビルド方法

1. Visual Studio 2022をインストール
2. WiX Toolset v3.11以降をインストール
3. ソリューションを開いてビルド
